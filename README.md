# Lepra Mobile

Пользовательский скрипт, который делает [leprosorium.ru](https://leprosorium.ru) пригодным для чтения с телефона.

## Установка (iOS Safari)

1. Поставьте из App Store приложение **Userscripts** (автор Justin Wasack, бесплатное, открытый код).
2. Откройте приложение и выберите папку для скриптов.
3. Настройки → Приложения → Safari → Расширения → Userscripts → включить. Там же для `leprosorium.ru` поставьте «Всегда разрешать».
4. Положите `lepra-mobile.user.js` в выбранную для скриптов папку. Имя обязательно должно оканчиваться на `.user.js`.
5. Откройте Лепру, тапните левый значок в адресной строке → Userscripts → в списке должен появиться Lepra Mobile.

## Установка (Android Firefox)

1. В Firefox откройте меню (три точки) → Extensions (Расширения) → найдите **Tampermonkey** → Add.    
2. Firefox → меню (три точки) → Расширения → Tampermonkey → Панель управления (Dashboard) → Вкладка Утилиты (Utilities).
3. Поле Установить с URL (Install from URL) — вставьте туда:
```
https://raw.githubusercontent.com/neokrasav4ik/lepra-mobile/main/lepra-mobile.user.js
```
4. Нажмите Установить. Откроется страница подтверждения со списком того, что скрипт запрашивает, — там же будет кнопка установки.















Установка на Android по аналогии. На macOS скрипт не проверялся, но принципиальных препятствий нет: подойдёт любой менеджер пользовательских скриптов.

## Что делает

**Раскладка.** Добавляет `viewport`, убирает боковые колонки, снимает фиксированные ширины и проценты, рассчитанные на широкий экран. Отдельно немного разобраны: главная, страница поста с комментариями, поиск, профиль, «мои вещи», подсайты, список подсайтов, лента уведомлений.

**Комментарии.** Лесенка вложенности ужата с 28 пикселей до 13 с потолком на шестом уровне. Голосование возвращено из левой колонки в строку подписи и сделано всегда видимым — на десктопе оно появляется по наведению мыши, которого на телефоне не бывает.

**Своя навигация по комментариям.** Три кнопки справа: вверх, переключатель «новые / свои», вниз. Долгое нажатие (полсекунды) на стрелку вверх переносит в начало страницы, на стрелку вниз — в конец, к форме ответа. Родная навигация лепры после первого нажатия перехватывала тапы по всей странице, поэтому скрыта.

**Счётчики комментариев.** После кнопки обновления лепра догружает комментарии, но числа в панели фильтров оставляет прежними. Скрипт пересчитывает их по документу.

**Кнопка «наверх».** На страницах без комментариев — на главной, в подсайтах, в профиле — справа появляется одна стрелка, возвращающая к началу. Она показывается, только когда отлистан хотя бы экран.

**Картинки.** Штатное увеличение лепры отключено: оно подменяет узел и сбивает прокрутку к началу страницы. Файлы у лепры полноразмерные, поэтому деталь смотрится обычным щипком. Если хочется разворачивать узкие картинки по тапу, поставьте `imageTap: 'zoom'` в настройках.

**Видео.** Safari на iOS не загружает видео до касания и рисует пустой прямоугольник. Скрипт добывает первый кадр, не скачивая ролик целиком, и делает это по мере приближения к экрану, не больше двух роликов одновременно. Воспроизведение/пауза видео запускается по тапу на любом месте превью-картинки. Кнопка плей не срабатывает.

**Тёмная тема.** Кнопка слева от логотипа. Сделана инверсией с поворотом цветового тона: своей тёмной палитры у лепры нет, а ручная перекраска рассыпалась бы на подсайтах с их собственными стилями. Картинки и видео инвертируются обратно.

## Что скрипт НЕ делает

Не собирает и не передаёт никаких данных. Не обращается к сторонним серверам. Не трогает куки, пароли и содержимое форм. Не отправляет статистику.

Единственные сетевые запросы — подгрузка превью видео с тех же адресов, откуда их берёт сама лепра. Всё остальное — работа с DOM уже открытой страницы.

## Настройки

В начале файла есть блок `CFG`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `maxWidth` | `1024` | Ширина экрана, до которой работает адаптация. На широких экранах скрипт не вмешивается вовсе. |
| `videoPreload` | `'metadata'` | `'none'` — не качать ничего до нажатия плей. `'metadata'` — только заголовок файла, зато известны пропорции и блок не прыгает. |
| `videoPoster` | `'frame'` | `'frame'` — добывать первый кадр. `'seek'` — легче, но кадра обычно не даёт. `'none'` — не добывать, будет пустой прямоугольник. |
| `lookAhead` | `1200` | За сколько пикселей до экрана готовить медиа. Больше — превью успевает раньше, но растёт трафик. |
| `maxParallelVideos` | `2` | Сколько роликов готовить одновременно. |
| `scanBudget` | `6000` | Потолок на разовый обход DOM. Внутренности комментариев не обходятся вовсе. |
| `debug` | `true` | Отладочная панель. Перед повседневным использованием можно выключить. |

## Расход ресурсов

Лепра тратит около 150 элементов DOM на один комментарий — в подписи каждого лежат инлайновые SVG-иконки. Тред на тысячу комментариев это порядка 43 тысяч узлов только внутри ленты.

Скрипт с ними не работает: обход отсекает поддеревья комментариев и постов, потому что разметка внутри однотипна и уже покрыта правилами CSS. На тысяче комментариев обходится около 1300 элементов вместо 43 тысяч.

Что ещё сделано ради экономии:

- метки «уже обработано» хранятся в `WeakSet`, а не в `data`-атрибутах: на длинной странице это десятки тысяч атрибутов, которые иначе жили бы в памяти до закрытия вкладки;
- прокрутка не запускает ничего: новые узлы ловит `MutationObserver`, который срабатывает только когда есть что обрабатывать;
- подготовка видео идёт очередью не больше двух одновременно и только для роликов вблизи экрана;
- у обходов есть потолок `scanBudget`, дальше которого проход просто останавливается.

На старых устройствах с малым объёмом памяти основную нагрузку создаёт сама страница лепры, а не скрипт. Если тред совсем огромный, полезно уменьшить `lookAhead` и поставить `videoPoster: 'none'` — тогда видео не будут готовиться вовсе.

## Отладка

Панель открывается тремя быстрыми тапами по левому верхнему углу экрана или добавлением `#lmdebug` в адрес.

Она показывает: что вылезает за границы экрана, какие элементы накладываются друг на друга (с указанием позиционированного предка — обычно виновника), какие колонки плавают, состояние видео и журнал ошибок скрипта.

Кнопка **«тык по элементу»** включает инспектор: следующий тап (по проблемному элементу) покажет цепочку родителей и разметку элемента под пальцем. Это самый быстрый способ разобраться с новой поломкой — вместо перебора догадок.

Если находите проблему, приложите к описанию вывод панели: по нему видно причину, а не только симптом.

## Известные ограничения

- Подсайты со своим оформлением могут выглядеть по-разному: их стили скрипт не знает и разбирает эвристикой (снимает обтекание у колонок шире 40% экрана).
- Тёмная тема через инверсию искажает цвета: жёлтая подсветка своих комментариев становится синеватой, фотографии на подсайтах могут выглядеть непривычно.
- Форма быстрого создания поста скрыта — для этого есть отдельная кнопка в шапке. Вернуть можно, удалив одну строку в разделе «ЛЕНТА И ПОСТЫ».
