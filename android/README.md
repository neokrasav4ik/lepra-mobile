# Оправа для Андроида

Приложение вокруг `lepra-mobile.user.js`: своя иконка, своя сессия, внутри —
та же мобильная вёрстка, что даёт юзерскрипт в Safari и Firefox.

**Скрипт здесь не лежит.** Он один на весь проект и живёт в корне
репозитория; сборка копирует его в `assets` задачей `copyUserScript`. Второй
копии быть не должно — она рассинхронизируется в первую же неделю.

## Собрать

В облаке: вкладка **Actions** → **APK** → **Run workflow**. Готовый файл
появится на вкладке **Releases**, оттуда он ставится прямо с телефона.

На своей машине (нужен Android SDK):

```
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Что где

| файл | о чём |
|---|---|
| `MainActivity.kt` | окно, настройки WebView, впрыск скрипта, ссылки, файлы, видео, «назад», перетяг |
| `ScriptStore.kt` | откуда берётся скрипт: встроенный, скачанный, откат |
| `Diag.kt`, `DiagActivity.kt` | отчёт: движок, заголовки, куки (только имена), журнал ошибок |
| `app/build.gradle.kts` | версии, подпись, копирование скрипта в assets |

Отчёт открывается долгим нажатием по значку приложения или решёткой
`#appdiag` в адресе.

## Чего тут сознательно нет

- Второй копии скрипта.
- Своей тёмной темы, своей навигации, своего просмотрщика картинок — всё это
  уже сделано в скрипте, и приложение в это не лезет.
- Очистки кук и хранилища в любом виде. Внутри чужая сессия.
